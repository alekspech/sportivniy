# Задание 2. Поворот текстуры пули при стрельбе

## Что нужно сделать

Все изменения должны происходить в bullet.py в функции draw() у пули. Пуля создается и выстреливается в функции shoot() у RangedWeapon, мы считаем направление стрельбы, когда вычитаем из положения мыши положение игрока 

shoot_direction = mouse_position - player_position
shoot_direction = shoot_direction.normalize()

Поэтому, когда пуля создана, нам уже известно направление её полета, оно сохраняется в self.direction внутри класса Bullet.

Тебе нужно переписать функцию draw() у пули так, чтобы внутри функции происходил поворот текстуры пули. Чтобы повернуть текстуру, нам нужно посчитать угол поворота. Давай проверим поворот относительно горизонтального вектора, который направлен направо.

```
Вот небольшая подсказка, как построить такой единичный вектор.

up_vector = pygame.math.Vector2(0, -1)

то есть 0 по X и -1 по Y. Если помнишь, в pygame ось Y идет сверху вниз, поэтому вектор, который торчит наверх – это -1 по Y

left_vector = pygame.math.Vector2(-1, 0) # -1 по X, то есть вектор смотрит влево.

Сделай git pull, у тебя появится файлик game/minigame1.py, запусти его, там будет миниигра, которая поможет понять, как из направления получается угол.

```

На основе подсказки создай переменную right_vector. С помощью созданного горизонтального вектора посчитай угол поворота относительно направления пули. Сделать это можно с помощью функции, которая применяется к вектору, right_vector.angle_to(self.direction). Эта команда даст нам направление вращение против часовой стрелки, а текстура вращается по часовой стрелке, поэтому нужно взять отрицательное значение от полученного угла

bullet_angle = -right_vector.angle_to(self.direction)

Далее нам нужно повернуть текстуру на заданных угол, вызовем функцию pygame.transform.rotate

rotated_image = pygame.transform.rotate(self.image, bullet_angle)

Далее тебе нужно использовать повернутую текстуру вместо текстуры self.image, которая у нас по умолчанию. Для этого в последней строчке функции draw в вызове screen.blit поменяй self.image на rotated_image.
